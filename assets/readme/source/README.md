# README 视觉素材

`hero.svg` 使用项目现有的橙色、深蓝、绿色和字体，表现“选目标 → 选频率 → 看动作并打卡”的实际流程。它是可直接修改的静态 SVG，不依赖外部字体、脚本或图片。

`training.png`、`equipment.png`、`diet.png` 是本地 v2026.09.26.11 的真实页面截图，采集于 2026-09-26。浏览器使用隔离会话，窗口宽 390、高 960，选中减脂与每周四练；没有调用模型，没有使用用户日常浏览器的打卡和小记。

`showcase.webp` 将这三张截图排列在同一画布上，只调整尺寸和位置，不重画或修改页面内容。单张 PNG 保留完整尺寸，可从 README 打开查看。

更新截图时，在仓库根目录运行 `npm start`，通过 HTTP 打开页面，再选择以下界面：

- 训练：减脂、四练、周一，打开第三项“跑步机慢跑”，展示教学与 30 分钟倒计时。
- 器械：打开跑步机卡片，展示真实器械照片及说明。
- 饮食：定位减脂饮食和分时段建议，展示早餐卡片。

截图里的动作媒体保留页面上的 Gym visual 署名，使用范围见主 README 的“素材与使用范围”。截图只说明当前界面，不代表 AI 模型、线上发布或云同步已经验证。

完整的正文、链接、表格和命令保留在 Markdown 中。仅修改这些 README 素材时，不需要更新应用页面版本，也不需要为应用增加构建依赖。
